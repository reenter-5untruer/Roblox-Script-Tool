## FAQ

### What is XCutors?

XCutors is a curated collection and universal loader for several popular Roblox executors on Windows. It provides a single interface to manage, launch, and switch between Volt, Synapse Z, Potassium, and Wave.

### Which executors are included in the package?

The package ships with configurations and loader support for Volt, Synapse Z, Potassium, and Wave. Each executor can be selected and launched directly from the XCutors dashboard.

### What operating system is supported?

XCutors is designed exclusively for Windows desktop. It is tested on Windows 10 and Windows 11. Older versions such as Windows 7 or 8 may have limited compatibility.

### How do I update the executors?

The xcutorsLoader includes an automatic update checker that notifies you when a newer version of any executor is available. You can also manually check for updates from the dashboard settings.

### Do I need to disable my anticomponent software?

Some security tools may flag executor files due to their injection-based nature. If this occurs, you may need to add the XCutors folder as an exclusion in your anticomponent settings.

### Can I add my own scripts to the script hub?

Yes. You can place your Lua script files into the scripts folder within the XCutors directory, and they will appear in the built-in script hub for easy access.

### What should I do if an executor fails to attach?

First, ensure Roblox is fully loaded before attempting to attach. If the issue persists, try restarting both the loader and Roblox, or switch to a different executor from the dashboard.

### Is XCutors free to use?

Yes, XCutors is free and open source. However, individual executors included in the collection may have their own licensing or access requirements.
